# Citation

## How to cite this work

To cite **a specific release**, use the version-specific DOI below. To cite **the work as a whole** (always resolves to the latest version), use the concept DOI: [10.5281/zenodo.20114951](https://doi.org/10.5281/zenodo.20114951).

## v0.2.0 — manuscript and FRB 20121102A frequency-tag correction

### Plain Text

Alex Liu. (2026). *FRB Periodicity Investigation: A Falsifiable
Directed-Beam Test Pipeline* (v0.2.0). GitHub repository:
https://github.com/alexliu1420/frb-periodicity. DOI:
https://doi.org/10.5281/zenodo.20130447.

### BibTeX

```bibtex
@misc{liu2026frbperiodicity_v020,
  title        = {FRB Periodicity Investigation: A Falsifiable Directed-Beam Test Pipeline},

```
